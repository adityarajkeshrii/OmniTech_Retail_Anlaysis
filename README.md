# OmniTech_Retail_Anlaysis
OmniTech Retail Analytics is a Power BI solution that transforms raw retail datasets using Power Query into 3 interactive dashboards: Customer Demographics, Sales Analysis, and AI Key Influencer tracking. It monitors ₹45.96M in revenue, flags a 10.8% return rate risk, and reveals that discounts over 20% cut profits by an average of ₹1.28K
